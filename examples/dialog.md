# 示例对话

以下为「麦麦智能点餐 · 省钱补给助手」在接入 mcd-mcp 后的真实交互示意。

---

## 场景一：训练后高蛋白补给（网球教练视角）

**用户**：帮我看看附近麦当劳，领券后点一份训练后吃的，要高蛋白。

**助手**：
1. `auto-bind-coupons` → 已领取麦麦省当前 5 张券
2. `query-my-coupons` → 账户可用券 8 张（含刚领的）
3. `query-nearby-stores` → 最近门店：XX 路餐厅（距 800m）
4. `list-nutrition-foods` → 筛高蛋白：麦辣鸡腿堡（蛋白质 19g）、板烧鸡腿堡（21g）、吉士蛋堡（15g）
5. `query-meal-detail`（麦辣鸡腿堡套餐）→ 可替换：饮料换无糖可乐、加蛋 +2 元
6. `calculate-price`（用券后）→ 原价 ¥32.5，用「满 30 减 8」券后 **¥24.5**
7. 复述：「XX 路餐厅 · 麦辣鸡腿堡套餐(无糖可乐+加蛋) · 到店自取 · 应付 ¥24.5，确认下单吗？」
8. 用户确认 → `create-order` → 返回取餐二维码 / 支付链接

---

## 场景二：积分快过期提醒

**用户**：我积分快过期了，有什么能换的？

**助手**：
1. `query-my-account` → 可用 1280 分，其中 500 分将于 10/15 过期
2. `mall-points-products` → 推荐：巨无霸兑换券(800 分)、薯条券(400 分)、麦辣鸡翅券(500 分)
3. `mall-product-detail`（巨无霸兑换券）→ 有效期 30 天
4. 建议：「500 分即将过期，建议换麦辣鸡翅券刚好花完，不浪费」→ 用户确认 → `mall-create-order` → 返回券码

---

## 场景三：当月活动查询

**用户**：麦当劳这个月有啥活动？

**助手**：
1. `campaign-calendar` → 进行中：1024 程序员节「M-Code」；未来：万圣节桶
2. `available-coupons` → 可领活动券 3 张
3. 一并回报活动 + 一键 `auto-bind-coupons` 领券，提醒「程序员节期间 GitHub 认证可直接领巨无霸三件套券」

---

## 场景四：外送点餐

**用户**：不想出门，给我送到公司。

**助手**：
1. `now-time-info` → 校准时间 2026-10-09 15:30
2. `delivery-query-addresses` → 已有「公司」地址
3. `delivery-query-stores`（公司地址）→ 可配送门店 2 家
4. `query-meals` + `query-meal-detail` 选品 → `calculate-price`（含配送费）
5. 复述方案 → 确认 → `create-order`（就餐方式=外送）→ 返回支付链接
